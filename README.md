# animori-data

Русские названия аниме и соответствия номеров для [AniMori](https://github.com/foulnike/Animori).
Собирается роботом, лежит в выпусках. Без датасета каждое название при первом
показе — сетевой запрос, и список на сотню строк раскрашивается около двух минут;
с датасетом он выходит раскрашенным сразу.

**Состояние: работает** — программа читает датасет начиная с 3.0.0, свежий выпуск
`2026.09.28-1113`. **Источник — Шикимори** (`censored=false`), пары MAL → AniList
добирает AniList, пустые названия — anime365. Лицензия — CC0-1.0.

## Обслуживание: одна обязанность

**Раз в два месяца: Actions → build-names → Run workflow**, заодно галочка
`map_rebuild`. Расписание отключается после 60 дней без человеческой активности
(коммиты робота не считаются), а сторож `watch-dataset` в репозитории программы
сам поднимет задачу, если выпуски или карта застынут. Клиент при любом раскладе
живёт на предыдущем выпуске — пропущенная сборка это медленно, а не сломано.

## Что в выпуске

```
index.json               опись: версия, дата, происхождение, свежесть, отпечатки
titles-anime.json.gz     русские названия, шесть полей на тайтл
map-mal-anilist.json.gz  соответствия номеров MyAnimeList и AniList
```

Постоянные адреса — всегда свежий выпуск:

```
https://github.com/foulnike/animori-data/releases/latest/download/index.json
https://github.com/foulnike/animori-data/releases/latest/download/titles-anime.json.gz
https://github.com/foulnike/animori-data/releases/latest/download/map-mal-anilist.json.gz
```

Клиент берёт опись, решает по ней, качать ли остальное, и спрашивает её условным
запросом: между выпусками приходят `304` без тела. Файлы сверяются по отпечаткам
из описи. Токен не нужен, адреса публичные.

## Формы файлов

`index.json`, числа выпуска `2026.09.28-1113`:

```json
{
  "version": 1, "builtAt": "2026-09-28T11:13:10.160Z",
  "source": "shikimori", "sourceTag": "id-65080", "license": "CC0-1.0",
  "names": { "source": "shikimori.rip", "count": 30623, "russian": 26343,
             "cyrillic": 26331, "known": 1, "mode": "partial",
             "fullAt": "2026-09-13T21:39:58.470Z", "added": 27, "changed": 20, "gone": null },
  "map": { "count": 20852, "from": "id-65080", "builtAt": "2026-09-28T11:13:10.160Z",
           "inherited": false, "rebuilt": false, "added": 23, "dropped": 0,
           "seeded": 20829, "wave": "отработала" },
  "freshness": { "maxId": 65080, "freshDays": 180, "airedRecent": 483 },
  "files": [{ "name": "titles-anime.json.gz", "bytes": 1224924, "sha256": "..." }]
}
```

Неочевидные поля:

- `names.count` — записи, а не имена: пустой `russian` — ответ «имени нет», а не
  пропуск. `known` — мёртвая мерка, осталась ради чтения клиентом.
- `mode` и `fullAt` — каким был обход; отметка переходит в следующий прогон и
  решает, пора ли идти полным. `gone` у частичного обхода всегда null: пропаж он
  не видит.
- `map.inherited` — карта целиком из семени, то есть не свежая; `rebuilt` —
  переспрошены все пары. `dropped` важен: карта умеет уменьшаться, а по числу пар
  убыль не видна.
- `freshness.maxId` — старший номер каталога; сторож сверяет его с живым
  Шикимори и отличает живой срез от прошлогоднего.

`titles-anime.json.gz` после распаковки:

```json
{
  "v": 1, "tag": "id-65080", "builtAt": "2026-09-28T11:13:10.160Z", "count": 30623,
  "titles": [
    { "id": 5114, "name": "Fullmetal Alchemist: Brotherhood",
      "russian": "Стальной алхимик: Братство", "kind": "tv",
      "aired_on": "2009-04-05", "score": "9.1" }
  ]
}
```

`id` — номер тайтла на Шикимори, он же номер MyAnimeList. Записи с пустым
`russian` не выбрасываются: клиент читает пустоту буквально, «в выпуске пусто»
значит «за именем не ходить».

`map-mal-anilist.json.gz` после распаковки:

```json
{ "v": 1, "tag": "id-65080", "builtAt": "2026-09-28T11:13:10.160Z", "count": 20852, "pairs": [[5114, 5114]] }
```

Пара — `[номер MyAnimeList, номер AniList]`. Карта — страховка, а не основной
путь; унаследованная целиком называет в `tag` и `builtAt` выпуск, из которого
приехала. Сжатие — gzip, а не zstd: gzip распаковывается штатными средствами
браузера.

## Как собирается

`scripts/build-names.mjs` через `.github/workflows/build-names.yml`, без
зависимостей: каталог — `crawl.mjs`, выпуск — `release-files.mjs`, волны —
`enrich-map.mjs` и `enrich-names.mjs`, мелкое общее — `common.mjs`.

1. Семена прошлого выпуска: опись для сравнения, файл имён — семя обхода, файл
   карты — семя волны AniList; всё сверяется по отпечаткам.
2. План времени: `RUN_BUDGET` 300, `MAP_BUDGET` 150, `NAMES_BUDGET` 60 минут.
   Потолок задания GitHub — глухая отмена, он стоит на 350 и нужен только против
   зависания.
3. Обход каталога: частичный, то есть хвост за прошлой головой плюс идущее и
   анонсы, или полный раз в 30 дней; `censored=false` обязателен — без флага
   каталог обрывается на шесть тысяч записей раньше.
4. Приёмка до волн: не меньше 25 000 названий, усадка не больше 5%, голова не ниже
   прошлой, карта не меньше семени. Не прошла — падает сразу, а не через час
   обогащения.
5. Волна карты: AniList пачками по 50 (`idMal_in`), пауза 2500 мс (лимит 30 в
   минуту); семя остаётся опорой, пара уходит только по доказанному отсутствию.
6. Волна имён: anime365 по одному номеру, берётся только кириллица; отдача низкая
   (36 имён на 4 021 тайтл за час), поэтому номера без ответа не переспрашиваются
   180 дней.
7. Публикация: gzip, отпечатки, опись, выпуск отдельным шагом; провал ничего не
   публикует и падает громко.

Адреса Шикимори: `shikimori.rip`, `shikimori.io`, `shikimori.one` по порядку, после
трёх отказов уходим на следующий; у anime365 — `anime365.ru`,
`smotret-anime.online`. Токен сборщику не нужен: свой прошлый выпуск публичен. Волны
выключаются входом `waves` или `BUILD_ANILIST=off` / `BUILD_ANIME365=off`.

### Расписание

Понедельник 04:27 UTC плюс запуск кнопкой; обычная неделя — 13 минут, худший из
виденных прогонов 100. По расписанию публикует всегда, обе волны гоняет, карту не
пересобирает; обе ручные сборки разом не сходятся.

| Вход                 | Что делает                                              |
| -------------------- | ------------------------------------------------------- |
| `pause`              | пауза между страницами Шикимори, мс, по умолчанию 700  |
| `anilist_pause`      | пауза между пачками AniList, мс, по умолчанию 2500     |
| `publish`            | снять галочку — собрать и посмотреть итог, ничего не выпуская |
| `waves`              | обе волны, только карта, только имена, никакие          |
| `map_rebuild`        | переспросить у AniList все пары до одной                |
| `names_full`         | обойти каталог полностью, не дожидаясь планового        |
| `budget`             | минут волне имён, по умолчанию 60                       |
| `run_budget`         | минут всему прогону, по умолчанию 300                   |
| `map_budget`         | сколько из них позволено волне карты, по умолчанию 150  |

После удавшегося выпуска робот пишет тег в `.github/last-build`, рядом едет журнал
волны имён.
